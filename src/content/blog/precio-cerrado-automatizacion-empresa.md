Si diriges una empresa, lo último que necesitas es un proyecto de software que se alarga y se convierte en un pozo sin fondo. O un desarrollo con IA que promete mucho y no resuelve el problema real del negocio. En Bitdesal no empezamos directamente a programar: **antes de escribir código hace falta entender el porqué y el cómo**.

<blockquote class="bf-pullquote">Automatizar sin entender el proceso es solo conseguir que el error ocurra más rápido.</blockquote>

<h2 class="bf-section-heading">
  <span class="bf-section-num" aria-hidden="true">01</span>
  <span class="bf-section-title"><span class="bf-section-lead">Antes de automatizar,</span> <span class="bf-section-accent">hay que saber dónde se pierde el tiempo</span></span>
</h2>

Antes de escribir una línea de código hay preguntas que casi nunca tienen respuesta obvia en la primera reunión. Si no las contestas, el proyecto se dispara.

<div class="bf-triptych">
  <div class="bf-triptych-col">
    <span class="bf-triptych-num">01</span>
    <h3>Frecuencia</h3>
    <p>¿Cada cuánto se repite la tarea? Lo que se hace una vez al trimestre no se automatiza igual que lo que se hace cada mañana.</p>
  </div>
  <div class="bf-triptych-col">
    <span class="bf-triptych-num">02</span>
    <h3>Variabilidad</h3>
    <p>¿Es siempre igual o hay excepciones? Las excepciones no vistas acaban en tickets y parches a mano.</p>
  </div>
  <div class="bf-triptych-col">
    <span class="bf-triptych-num">03</span>
    <h3>Impacto real</h3>
    <p>¿Cuánto tiempo y dinero ahorra de verdad? Sin número, no hay forma de priorizar frente a otras inversiones.</p>
  </div>
</div>

<h2 class="bf-section-heading">
  <span class="bf-section-num" aria-hidden="true">04</span>
  <span class="bf-section-title"><span class="bf-section-lead">Por qué el</span> <span class="bf-section-accent">precio cerrado importa</span></span>
