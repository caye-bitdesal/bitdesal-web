If you run a company, the last thing you want is a software project that drags on, keeps changing shape and ends up costing twice what you expected. That is why at Bitdesal we do not start by coding: first we do a **process study** at a fixed price.

## What the study includes

In about ten hours of work (more if several departments or systems are involved) we review how the task that eats most of your time is done today: approvals, documents, data copied by hand, and so on. The deliverable is concrete:

- A diagnosis of what is slowing the process down
- A proposed solution (with or without AI, depending on whether it pays off)
- A phased plan
- A **fixed quote** for the implementation

The study costs **€450 + VAT**. If you hire the implementation within the next 30 days, **it is credited in full**.

## Why a fixed price matters

A fixed quote forces the scope to be defined before any code is written. If during the study we see that investing does not pay off, we say so: there is no point selling you something that will not actually save hours.

When it does pay off, the implementation follows the same rule: the agreed price does not change unless **you and we widen the scope in writing**.
